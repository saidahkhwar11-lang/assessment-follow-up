# Components

The current project keeps its page-specific React components directly inside the Next.js App Router files:

- `app/page.tsx` — landing page
- `app/teacher/page.tsx` — Teacher Portal and tracker components
- `app/admin/page.tsx` — Admin Portal and follow-up components
- `app/layout.tsx` — shared application layout

These files are included in full and are editable. This folder is reserved for shared components if the project is split into smaller modules later.
